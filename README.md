# Ingeniería de Software 2 - Introducción

Bienvenidos a la clase de **Ingeniería de Software 2** en la Universidad Autónoma de Entre Ríos (UADER). Este curso se enfoca en conceptos avanzados de desarrollo de software, con énfasis en la gestión de configuración y el uso de herramientas colaborativas como GitHub.

## Descripción del Curso

En esta asignatura, exploraremos las mejores prácticas para gestionar la configuración de proyectos de software a lo largo de su ciclo de vida. La gestión de configuración es fundamental para mantener la integridad, la trazabilidad y la colaboración en equipos de desarrollo.

## Temas Principales

- **Gestión de Configuración**: Conceptos básicos, importancia en el desarrollo de software, y herramientas para implementar control de versiones.
- **Git y GitHub**: Uso de Git para control de versiones, flujos de trabajo colaborativos, pull requests, issues, y integración continua.
- **Herramientas Relacionadas**: Exploración de plataformas como GitHub para alojar repositorios, gestionar proyectos y fomentar la colaboración abierta.

## Objetivos de Aprendizaje

Al finalizar el curso, los estudiantes serán capaces de:
- Comprender los principios de la gestión de configuración en proyectos de software.
- Utilizar Git de manera efectiva para controlar versiones de código.
- Colaborar en proyectos utilizando GitHub, incluyendo la gestión de ramas, merges y revisiones de código.
- Aplicar prácticas de DevOps básicas relacionadas con la configuración y el despliegue.

## Requisitos Previos

- Conocimientos básicos de programación (preferiblemente en lenguajes como Java, Python o similares).
- Familiaridad con conceptos fundamentales de ingeniería de software.
